
# Portfolio Website – Abhranil Dutta 🌐

This is my personal portfolio website created using **HTML, CSS, and JavaScript**.  
Deployed live at 👉 [abhranil-dutta.netlify.app](https://abhranil-dutta.netlify.app)

---

## 🛠 Tech Stack
- **HTML5** – Structure  
- **CSS3** – Styling & responsive design  
- **JavaScript (ES6)** – Interactivity  
- **Google AdSense** – Integrated for ads  
- **Netlify** – Deployment & hosting  

---

## ⚡ Features
- Fully responsive design (works on desktop, tablet, and mobile)  
- Project showcase with descriptions and images  
- Certificates and achievements section  
- Contact form integration  
- Google Ads integration for monetization  

---

## 🚀 How I Built It
1. Designed the structure with **HTML**  
2. Styled the layout and made it responsive using **CSS**  
3. Added dynamic interactions with **JavaScript**  
4. Integrated **Google Ads** for monetization  
5. Deployed on **Netlify** for free hosting with continuous deployment
